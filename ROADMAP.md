# IoT learning roadmap

## Available

Experiment-design exercise, four track outlines and a tutorial template.

## Planned

1. Select and document a concrete hardware/firmware combination for each track.
2. Publish a bench setup with permitted radio settings and synthetic messages.
3. Measure delivery, timing and power where supported with repeatable procedures.
4. Publish sanitized results and explain measurement limits.

## Publishing criteria

Record exact equipment, versions, antennas, region, test conditions, raw-data method and repetitions. Remove keys, private locations and personal messages. Separate measured values from estimates. Do not label a hardware combination supported before it is tested.
